# DataBridge IntelliJ Plugin

IntelliJ IDEA plugin for DataBridge `.bridge` files.

## Features

- Syntax highlighting for `.bridge` files
- Custom file icon
- Color customization in IDE settings

## Installation

1. Download the plugin `.jar` from the [releases page](https://github.com/chauketlou8-tech/databridge/releases)
2. In IntelliJ IDEA: `Settings` → `Plugins` → ⚙️ → `Install Plugin from Disk`
3. Select the `.jar` file
4. Restart IntelliJ IDEA

## Syntax Highlighting

| Keyword | Color |
|---------|-------|
| `let`, `const` | Orange |
| `string` | Green |
| `number` | Blue |
| `new` | Purple |

Colors can be customized in `Settings` → `Editor` → `Color Scheme` → `DataBridge`

## File Association

`.bridge` files are automatically associated with the DataBridge language.
