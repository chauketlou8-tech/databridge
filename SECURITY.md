# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

If you discover a security vulnerability in DataBridge, please do not open a public issue.

Instead, email us at: **security@databridge.dev**

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## What to Expect

When you report a vulnerability:

1. We will acknowledge receipt within 48 hours
2. We will investigate and validate the issue
3. We will work on a fix and coordinate disclosure
4. We will credit you in the release notes (if you wish)

## Disclosure Policy

- We will disclose vulnerabilities responsibly
- We will coordinate with reporters before public disclosure
- We will release fixes as soon as possible

## Security Best Practices

When using DataBridge:

- Always use the latest version
- Keep your database credentials secure
- Use environment variables for sensitive data
- Enable SSL/TLS for database connections
- Regularly update dependencies
