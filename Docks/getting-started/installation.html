Installation

Using npm

npm install databridge

Using yarn

yarn add databridge

Using pnpm

pnpm add databridge

Peer Dependencies

Depending on your database, install the appropriate driver:

PostgreSQL

npm install pg

MySQL

npm install mysql2

MongoDB

npm install mongodb

SQLite

npm install sqlite3
