Data Types

DataBridge supports a wide range of data types for schema definitions.

Primitive Types

STRING   - Text values - "hello world"
NUMBER   - Numeric values - 42, 3.14
BOOLEAN  - True or false values - true, false
DATE     - Date and time values - 2026-07-31T00:00:00.000Z

Complex Types

OBJECT   - Key-value pair objects - { name: "John", age: 30 }
ARRAY    - List of values - [1, 2, 3], ["a", "b", "c"]
BUFFER   - Binary data - images, files, encrypted data

Special Types

UUID     - Universally unique identifiers - 123e4567-e89b-12d3-a456-426614174000
DECIMAL  - High-precision decimal numbers - 99.99, 0.0001
ENUM     - Predefined text values - "RED", "GREEN", "BLUE"
JSON     - JSON data - {"key": "value"}
TEXT     - Long text content - Multi-paragraph content

Auto Types

ID       - Auto-generated identifier
CREATED_AT - Auto-populated creation timestamp
UPDATED_AT - Auto-populated update timestamp

Reference Types

REFERENCE - Reference to another model - User.id
RELATION  - One-to-many or many-to-many relationship
