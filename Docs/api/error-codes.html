Error Codes

DataBridge uses a standardized error code system for consistent error handling.

Provider Errors (00x)

D001 - Provider not specified
D002 - Invalid provider
D003 - Provider not supported
D004 - Provider configuration missing
D005 - Provider connection failed
D006 - Provider error

Connection Errors (01x)

D010 - Connection timeout
D011 - Connection refused
D012 - Connection closed
D013 - Invalid connection URL
D014 - SSL/TLS error
D015 - No connection
D016 - Connection error

Driver Errors (02x)

D020 - Driver not found
D021 - Driver initialization failed
D022 - Driver incompatible
D023 - Driver version mismatch
D024 - Driver URL missing
D025 - Driver error

Query Errors (03x)

D030 - Invalid query syntax
D031 - Query execution failed
D032 - Query timeout
D033 - Invalid query parameter
D034 - Query result empty
D035 - Query not provided
D036 - Query error

Schema Errors (04x)

D040 - Invalid schema definition
D041 - Schema validation failed
D042 - Schema migration failed
D043 - Schema already exists
D044 - Schema not found
D045 - Schema error

Model Errors (05x)

D050 - Model not found
D051 - Model already exists
D052 - Invalid model definition
D053 - Model validation failed
D054 - Model creation failed
D055 - Model error

Transaction Errors (06x)

D060 - Transaction failed
D061 - Transaction timeout
D062 - Transaction already started
D063 - Transaction not started

Special Errors (08x)

D080 - Mismatch error
D081 - Null error
