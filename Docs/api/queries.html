Query API

Query Builder

Build queries using a fluent interface.

where()

Adds a filter condition.

User.where("age").greaterThan(18).execute();

sort()

Sorts results.

User.sort("name", "asc").execute();

limit()

Limits the number of results.

User.limit(10).execute();

skip()

Skips a number of results.

User.skip(20).execute();

select()

Selects specific fields.

User.select("name", "email").execute();

Complete Example

const users = await User
    .where("age")
    .greaterThan(18)
    .sort("name", "asc")
    .limit(10)
    .select("name", "email")
    .execute();
