A unified, type-safe database abstraction layer for TypeScript and Node.js. Stop learning different query languages. Start building.

Get Started View on GitHub
PostgreSQL MySQL MariaDB MongoDB SQLite CouchDB
TypeScript 
import { DataBridge, Schema } from "databridge";

const db = await DataBridge.connect({
    provider: "postgres",
    url: "postgres://localhost:5432/myapp"
});

const User = await db.model("User", new Schema({
    name: String,
    email: String,
    age: Number
}));

await User.create({
    name: "John",
    email: "john@example.com",
    age: 21
});

const users = await User.find();

Why DataBridge?

Unified API

One consistent interface across all supported databases. No vendor lock-in.

TypeScript First

Full type safety with IntelliSense. Catch errors at compile time.

Extensible

Add any database with a simple driver interface.

Schema Validation

Define and validate your data structures with built-in validators.

Error Code System

Standardized error codes for consistent error handling.

Model Support

Full CRUD operations with type safety.

Query Builder

Fluent database-agnostic queries.

Migration System

Version control for your database schema.
